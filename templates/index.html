🗄️ 数据管理
开奖数据来自 GitHub 上自动同步香港赛马会官方开奖的开源数据集 （1993 年至今约 4400 期，国内直连可用，无需翻墙）。 导入会清空并替换当前的模拟数据。

🛡️ 安全说明
  • 配置保存在项目目录下的 data/settings.json，该文件已加入 .gitignore，不会被提交到 git。
  • API Key 不会回显到页面上，接口只返回末 4 位用于核对；留空提交表示保持原值。
  • Key 以明文存于本机文件，请勿把该文件分享或上传到任何公开位置。
  • 本工具所有请求都由你的浏览器经本机 Flask 服务转发到你填写的接口，不经过任何第三方中转。
⚠️ 本工具仅供数据分析学习与娱乐参考，不构成任何投注建议。彩票开奖为独立随机事件，历史数据不代表未来结果。请理性对待，量力而行。
